One funny single-line excuse a developer gives when code breaks in
production, written by `main.py` to `/output/entry.txt`.

> It worked on my machine. Production is the same machine — just with
> more users, less memory, and a personal grudge against me.

Built for the [make.fun](https://make.fun) bounty "Make the AI Judge Laugh:
Developer Excuses" — a blind pairwise judged competition.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only, deterministic: every run writes the same 126-character line.
